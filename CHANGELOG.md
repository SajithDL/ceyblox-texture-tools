# Changelog

## 1.0.0-beta.4 — 2026-10-21

- Split the panel into eight independent collapsible sections.
- Added a fixed-height texture list with settings for the selected image.
- Improved labels, action grouping and status readability in a narrow sidebar.
- Moved creator credit and version information to the bottom.

## 1.0.0-beta.3 — 2026-10-21

- Renamed the sidebar tab to CBT Tools and updated installation instructions.

## 1.0.0-beta.2 — 2026-10-21

- Refined public documentation and contributor instructions.
- Updated release packaging.

## 1.0.0-beta.1 — 2026-10-21

First packaged Ceyblox release, replacing the earlier single-file converter.

- Real DDS encoding; no renamed-image fallback.
- Multi-object conversion and node-group traversal.
- DDS compression selection, mip chains and alpha protection.
- Separate Convert, Resize and combined actions.
- Fit, Fill and Stretch modes with size presets and custom dimensions.
- Per-image purpose and compression settings.
- Selected-object material isolation, manifest-based relinking and restore.
- Filename matching with DDS priority and ambiguity checks.
- Restricted experimental UV transforms with backups.
- Image-engine installer, progress, cancellation and results log.
- Install ZIP, source repository, tests and GitHub release workflow.
